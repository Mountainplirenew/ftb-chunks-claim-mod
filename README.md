# FTB Chunks — Chunk Claiming Mod

[![Download Latest](https://img.shields.io/github/v/release/Mountainplirenew/ftb-chunks-claim-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Mountainplirenew/ftb-chunks-claim-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Claim chunks to protect your base, force-load them, and manage team territories on a visual map.

## Features

- Claim chunks to prevent griefing from other players
- Force-load chunks to keep machines running offline
- Team-based claiming with shared territory management
- Visual map overlay showing claimed and force-loaded chunks
- Configurable claim limits per player and team

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
